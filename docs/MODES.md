## Что выбрать для своей задачи

| Задача | Начальный вариант |
|---|---|
| Discord, YouTube, сайты | Оптимизатор: общая стратегия Phantom или автоподбор |
| Игра из каталога v4.2.0 | Оптимизатор: «Для игр» → игра → профиль → «Применить» |
| Защищённый DNS | TurboDNS, отдельно или с Оптимизатором |
| Туннель для выбранной игры или приложения | SecureLink PRO и правила маршрутизации |
| Уменьшение фоновой нагрузки ПК | Performance Hub PRO |

**Игровой профиль** меняет правила Оптимизатора. **Маршрут SecureLink** выбирает приложение для VPN. **Performance Hub** управляет ресурсами ПК. Эти функции решают разные задачи; изменение одной не подтверждает исправность остальных.

## Матрица совместимости

| Оптимизатор | Game Filter | SecureLink | TurboDNS | Результат |
|:---:|:---:|:---:|:---:|---|
| ✓ | — | — | — | Базовая оптимизация выбранной стратегией |
| ✓ | ✓ | — | — | Обработка игрового и голосового трафика |
| ✓ | ✓/— | ✓ | — | Оптимизация плюс VPN для PRO |
| ✓ | ✓/— | — | ✓ | Оптимизация плюс защищённый DNS |
| — | — | ✓ | — | Только SecureLink VPN |
| — | — | — | ✓ | Только TurboDNS |
| любое | любое | ✓ | ✓ | Не допускается: оба модуля управляют DNS |

Game Filter является частью Оптимизатора, а не самостоятельным VPN. Обычно оставляйте `TCP + UDP` и стандартные порты. Ручная смена портов без понимания сценария может ухудшить связь.

## Что показывает статистика

- При работе только Оптимизатора отображается трафик компьютера.
- При включённом SecureLink отображается трафик VPN-туннеля.
- TurboDNS влияет на состояние DNS, но не подменяет общий счётчик трафика.
- Доступность сервисов проверяется отдельно от наличия VPN.
- TCP-отклик и результат проверки сайта не равны игровому пингу и не подтверждают вход в матч.

## Диагностика игрового подключения

1. Проверьте состояние серверов игры и обычное подключение без StabiLink. Зафиксируйте исходный результат.
2. Закройте игру и сторонние сетевые фильтры, которые могут конфликтовать. Не меняйте несколько модулей одновременно.
3. Для WARDOGS, Mistfall Hunter, PEAK, R.E.P.O., Fallout 76, Rainbow Six Siege, Dead by Daylight, Marvel Rivals или THE FINALS выберите профиль в **«Стратегии → Для игр»** и нажмите **«Применить»**.
4. Включите Оптимизатор, проверьте активное имя стратегии, затем запустите игру. Сравните вход, лобби, матч и голосовую связь.
5. Если сбой остался, закройте игру и сравните следующий профиль той же игры. Настройку SecureLink при сравнении оставляйте одинаковой.
6. Если THE FINALS работает без Оптимизатора и перестаёт с ним, попробуйте **Phantom (THE FINALS ALT)**: прямое подключение игровых сервисов и сохранение настроек Discord/YouTube.
7. При необходимости отдельно проверьте SecureLink PRO и выбранный маршрут игры. Изменения маршрутов применяются при следующем подключении VPN.
8. При повторении ошибки сохраните игру, профиль, модули, точное время с часовым поясом и результат каждого сравнения. Полный отчёт передайте в личную поддержку.

Автоподбор тестирует 8 общих стратегий, а не 28 игровых профилей. Для игры требуется ручная проверка сессии. Сетевой профиль не исправляет любой UE/Fatal Error, античит, бан, очередь или массовый сбой серверов.

## Диагностика Discord, YouTube и сайтов

1. Проверьте обычный интернет и исключите конфликт стороннего VPN или фильтра.
2. Включите только Оптимизатор, начните с Phantom.
3. Выполните встроенную диагностику, затем автоподбор общих стратегий.
4. Повторите реальное действие: запуск Discord, голосовой канал или воспроизведение видео.
5. SecureLink и TurboDNS проверяйте отдельно. Меняйте один параметр за раз.

При полном исчезновении интернета укажите момент включения модуля и время обрыва. Успешное открытие одного сайта не доказывает исправность всех маршрутов. [Ответы на частые вопросы](FAQ.md#discord-youtube).
