## Для чего нужны журналы

Локальные журналы помогают понять:

- прошёл ли запуск приложения;
- какой модуль включался или завершался;
- успешно ли применена стратегия;
- произошла ли ошибка обновления;
- на каком этапе остановилась диагностика.

## Автоматическая защита

Перед записью StabiLink маскирует чувствительные категории данных: данные авторизации, токены, ключи, закрытые служебные адреса, подписочные ссылки и локальные пользовательские пути. Та же очистка применяется при формировании диагностического архива.

## Что нельзя публиковать

- QR-коды авторизации;
- комбинации подтверждения устройства до окончания входа;
- токены и ключи;
- подписочные URL;
- содержимое персонального профиля;
- полные необработанные журналы;
- скриншоты с личными сведениями без предварительной проверки.

## Как безопасно сообщить об ошибке

1. Запишите точное время сбоя с часовым поясом, игру или сервис, выбранную стратегию и включённые модули. Укажите полное название профиля, например Phantom (WARDOGS ALT).
2. Повторите проблему один раз, если это безопасно для текущей сессии.
3. Для полной проверки откройте **«Диагностика → Проверить подключение»** и дождитесь готового ZIP.
4. Если нужен журнал, откройте **«Логи»**. Найдите нужную запись и скопируйте её либо выберите **«Сохранить журнал»**.
5. Просмотрите материалы перед отправкой. К публичному Issue приложите только нужный очищенный фрагмент.
6. Полный архив передавайте через личный канал поддержки.

Даже при автоматической маскировке пользователь должен самостоятельно проверить материалы перед публикацией.

## Диагностический ZIP

По кнопке **«Проверить подключение»** StabiLink собирает результаты сетевых проверок, состояние подключения и журналы приложения. На экране видны этапы сбора. После завершения отчёт сохраняется на рабочем столе, а **«Показать ZIP-отчёт»** выделяет его в Проводнике.

Маскировка применяется при формировании архива. Просмотрите содержимое и отправьте файл через личную поддержку самостоятельно. Для короткого описания системы можно скопировать версию приложения и Windows из **«О программе → Скопировать сведения»**.
