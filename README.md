## Стратегии Оптимизатора

Стратегия — набор способов обработки соединений. Оптимизатор трафика доступен бесплатно, работает на вашем компьютере и сам по себе не является VPN: он не меняет внешний IP-адрес и не обещает анонимность.

| Стратегии в 4.1.3 | Когда попробовать |
|---|---|
| **Phantom**, **Phantom Stealth** | Начальный выбор для поддерживаемых сайтов, видео и голосовых сервисов. |
| **Phoenix**, **Phoenix ALT** | Альтернатива, если Phantom не подходит провайдеру, в том числе при долгой проверке обновлений Discord. |
| **Phantom Phoenix**, **Phantom Phoenix ALT** | Гибридные варианты: возможности Phantom с другим способом веб-подключения Discord. |
| **Vector** | Меняет порядок отправки частей запроса; основной веб-режим обходится без подставного TLS-образца. |
| **Prism** | Использует выборочную обработку части запроса и его разбиение. |
| **Phantom (MH)** | Отдельные правила для Mistfall Hunter. |
| **Phantom (WARDOGS)**, **Phantom (WARDOGS ALT)** | Вход в WARDOGS и подключение к матчам на основе Phantom. |
| **Phoenix (WARDOGS)**, **Phoenix (WARDOGS ALT)** | Игровые правила WARDOGS с веб-подключениями семейства Phoenix. |

**Автоподбор** сравнивает восемь общих стратегий и подтверждает результат повторной проверкой. Пять игровых профилей выбираются вручную: доступность сайта не подтверждает вход в игровой матч.

### Экспериментальные функции

- **Автосмена варианта при сбоях** пробует резервные способы внутри выбранной стратегии. Для Vector и Prism предусмотрены три веб-резерва и два резерва для QUIC-соединений.
- **TLS-образец по текущему приложению** использует форму запроса там, где это предусмотрено правилами. Если она не подходит, сохраняется штатный образец.
- **Запомнить удачные варианты** включает адаптацию и сохраняет историю отдельно для разных сетей. История зашифрована и остаётся на компьютере.
- **Группировать повторные отправки** уменьшает число обращений к сетевому компоненту при повторной отправке пакетов.

Запасные способы применяются с учётом отдельных соединений; игровые и голосовые правила не заменяются веб-резервами. Изменения настроек применяются при следующем запуске Оптимизатора. Набор применяемых функций зависит от выбранной стратегии.

## Performance Hub — Оптимизатор ПК

**Включите оптимизацию и запускайте игру.** StabiLink проверяет доступные настройки Windows и применяет подходящие изменения, чтобы освободить ресурсы и помочь уменьшить просадки FPS из-за фоновой нагрузки.

- **Умный режим** определяет игровой сценарий и возвращается к повседневному после завершения игры.
- **Память под контролем:** очистка при включении оптимизации и автоматически при высокой загрузке ОЗУ.
- **Ресурсы для игры:** временное снижение приоритета подходящих фоновых программ при перегрузке компьютера.
- **Производительное питание:** выбор или создание подходящей схемы, если компьютер это поддерживает.
- **Возврат настроек:** при отключении оптимизации восстанавливаются изменённые параметры, питание и временно остановленные службы.

![Performance Hub в StabiLink 4.0](assets/utilities.png)

Найдите его в **«Утилиты → Производительность»**. Панель в компактном режиме и индикатор в трее показывают состояние оптимизации. У пользователей PRO подготовка ПК по умолчанию включается вместе с оптимизацией трафика; сохранённый выбор пользователя учитывается.

Процент на спидометре показывает **готовность настроек ПК**, а не прирост FPS. Результат зависит от игры, компьютера и фоновой нагрузки. Разгон видеокарты и ручные замеры кадров для работы функции не нужны.

## Подключение без лишних действий

| Модуль | Для чего нужен |
|---|---|
| **Оптимизатор трафика** | Подготовленные стратегии обработки трафика, включая Phantom. Если текущий вариант не помогает, доступен автоподбор. |
| **Game Filter** | Настройки обработки игрового и голосового трафика. |
| **TurboDNS · FREE и PRO** | Защищённые DNS-запросы через Cloudflare, Quad9 или Comss. Не скрывает IP и не заменяет VPN. |
| **SecureLink · PRO** | VPN-подключение и маршрутизация выбранных игр и приложений. |
| **Sub URL · PRO** | Подключение совместимых клиентов на телефоне — [инструкция Karing](docs/KARING.md). |

TurboDNS и SecureLink работают по отдельности: оба управляют DNS. Оптимизатор трафика может работать совместно с подходящим режимом. Подробнее — [режимы работы](docs/MODES.md).

## Стратегии для WARDOGS и Mistfall Hunter

В **релиз 4.1.3 включены все пять игровых профилей** из таблицы выше. Они доступны в бесплатном Оптимизаторе трафика; подписка PRO для них не нужна.

**Mistfall Hunter:** выберите **Phantom (MH)**. Профиль содержит отдельные правила игровых соединений и сохраняет веб-возможности Phantom.

**WARDOGS:** начните с **Phantom (WARDOGS)**. Если подключение не устанавливается, сравните **Phantom (WARDOGS ALT)** и варианты **Phoenix (WARDOGS)** / **Phoenix (WARDOGS ALT)**. Они отличаются обработкой веб-соединений и авторизации, сохраняя отдельные правила подключения к матчу.

1. Закройте игру и выберите профиль вручную в StabiLink.
2. Запустите или перезапустите Оптимизатор, чтобы применить выбор.
3. Откройте игру и проверьте вход и подключение к матчу.
4. Если сбой повторяется, сравнивайте варианты по одному и сохраните время ошибки для обращения в поддержку.

Профили рассчитаны на проблемы подключения, связанные с фильтрацией трафика. Они не исправляют UE/Fatal Error, ошибки видеодрайвера или античита, очередь на вход и сбой серверов игры. Включение в релиз не означает гарантированную работу на каждом провайдере.

## Быстрый старт

1. Скачайте **`StabiLink-Desktop-v4.1.3-win-x64.zip`** из [релиза 4.1.3](https://github.com/sany86russ/StabiLink-Desktop/releases/tag/v4.1.3).
2. Распакуйте архив в отдельную постоянную папку. Не запускайте приложение прямо из ZIP.
3. Запустите **`StabiLink.Desktop.exe`** и подтвердите запрос Windows на права администратора.
4. Войдите в аккаунт. Для первого входа удобно выбрать **«Email код»** — [подробная инструкция](docs/FIRST_START.md).
5. Выберите **Phantom** и включите Оптимизатор трафика. При необходимости используйте автоподбор.

Уже пользуетесь StabiLink? Откройте уведомление о новой версии. В отдельном окне обновления доступны список изменений, ход загрузки, отмена и повторная попытка при ошибке.

### Проверка подлинности сборки

Рядом с архивом опубликован файл `.sha256`. В PowerShell выполните:

```powershell
Get-FileHash .\StabiLink-Desktop-v4.1.3-win-x64.zip -Algorithm SHA256
```

Сравните результат с файлом **`StabiLink-Desktop-v4.1.3-win-x64.zip.sha256`** из того же релиза. Контрольная сумма помогает обнаружить повреждение или изменение архива, но не заменяет загрузку из официального источника.

Если значение не совпадает, скачайте архив заново из официального релиза.

## Системные требования

- Windows 10 или Windows 11, **x64**.
- Права администратора для сетевых и системных функций.
- Подключение к интернету для входа, проверки подписки и обновлений.

Доступность отдельных настроек ПК зависит от Windows, оборудования и политик системы. Работа сетевых стратегий зависит от провайдера и текущих условий подключения.

## Частые вопросы

### Discord зависает на Checking for updates или Starting — что делать?

Перезапустите Discord после применения стратегии. Сравните Phoenix, Phoenix ALT или гибриды Phantom Phoenix, затем используйте автоподбор и диагностику. Меняйте по одному параметру: случайно удачный повторный запуск ещё не доказывает, что помогла последняя настройка.

### YouTube сообщает, что нет подключения к интернету?

Проверьте доступность других сайтов, затем запустите диагностику и автоподбор. Vector и Prism дают дополнительные варианты, а автосмена может подобрать резерв внутри выбранной стратегии.

### Нужно ли включать VPN для работы Оптимизатора?

Нет. Оптимизатор работает отдельно. SecureLink — дополнительный режим PRO для туннельного подключения и маршрутизации приложений. TurboDNS также доступен отдельно, но одновременно с SecureLink не включается.

### Нужно ли вручную устанавливать новый движок?

Нет. Необходимые компоненты поставляются с приложением. Скачайте готовый ZIP из релиза или обновитесь через StabiLink; подбирать и заменять служебные файлы вручную не требуется.

### StabiLink гарантирует рост FPS и снижение пинга?

Нет. Performance Hub помогает уменьшить влияние фоновой нагрузки, а сетевые модули решают задачи подключения. Результат зависит от компьютера, игры, провайдера и состояния серверов.

### Где скачать исходники или мобильное приложение?

Этот репозиторий содержит документацию и готовые Windows-сборки; исходники StabiLink не публикуются. Для Android и iOS используйте совместимый клиент и персональную Sub URL по [инструкции](docs/SUB_URL.md). Автоматические архивы GitHub «Source code» содержат только материалы этой публичной витрины и не являются установщиком.
